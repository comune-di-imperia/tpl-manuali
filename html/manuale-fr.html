Avant de commencer

De quoi s'agit-il et que faut-il ?

La navette autonome est un service de transport public expérimental : les navettes électriques circulent sur un tracé dédié avec à bord un opérateur toujours prêt à intervenir. La participation est volontaire et gratuite : pour monter à bord, il faut s'inscrire une seule fois et donner son consentement éclairé, comme le prévoit le décret qui autorise l'expérimentation.

Il vous suffit

  • d'un smartphone avec une connexion internet ;
  • d'une adresse e-mail accessible immédiatement (ou d'un compte Google) ;
  • de moins d'une minute pour finaliser l'inscription.

Aucune application à installer. Ouvrez le navigateur de votre téléphone et rendez-vous sur app-tpl.comune.imperia.it : la page fonctionne sur tout téléphone, tablette ou ordinateur. Vous pouvez l'ajouter à l'écran d'accueil pour la retrouver d'un seul geste.

À noter. L'application suit la langue de votre téléphone et existe en italien, anglais, français, allemand et espagnol ; vous pouvez aussi en choisir une autre depuis le sélecteur de langue de la page. Les boutons nommés dans ce manuel sont ceux que vous verrez en français ; les captures d'écran ont été prises en italien, la disposition est donc identique même là où les mots diffèrent.

Pas à pas

L'inscription

1Créer un compte

Lors de la première visite, choisissez Créer un compte. Saisissez votre adresse e-mail et un mot de passe d' au moins 10 caractères, puis appuyez sur Créer un compte.

Vous êtes pressé ? Sur l'écran de connexion, vous pouvez choisir Continuer avec Google : ni e-mail ni mot de passe ne sont nécessaires et vous passez directement au consentement. Le service ne reçoit que votre adresse et le nom communiqué par Google, jamais votre mot de passe.
L'écran de création du compte.
2Confirmer l'adresse e-mail

Après l'envoi, un message vert de confirmation apparaît : si l'adresse est valide, vous recevrez un e-mail contenant le lien à ouvrir.

Le message provient de Bus autonome — expérimentation ; les réponses éventuelles vont à tplauto@comune.imperia.it.

Rien reçu ? Vérifiez le dossier des courriers indésirables. Passé 24 heures, le lien n'est plus valable : refaites la demande depuis l'écran de création du compte.
L'avis confirmant l'envoi du message.
L'e-mail de confirmation : ouvrez le lien sous 24 heures.
3Finaliser la confirmation

Le lien ouvre cet écran : appuyez sur Confirmer l’adresse pour achever la vérification. C'est la dernière étape de la création du compte.
Un seul geste pour achever la vérification.
4Se connecter

Revenez sur la page de connexion : l'avis vert « Adresse confirmée » indique que tout est en ordre. Saisissez e-mail et mot de passe et appuyez sur Se connecter.

Mot de passe oublié ? Utilisez Mot de passe oublié sous le bouton : vous recevrez par e-mail les instructions pour en choisir un nouveau.
Connexion avec identifiants ou avec Google.
Pas à pas

Le consentement et vos données

5Lire la notice d'information

L'écran Bienvenue à bord présente l'expérimentation. Touchez Politique de confidentialité pour l'ouvrir : elle est rédigée en termes simples et explique quelles données sont collectées, qui les consulte et combien de temps elles sont conservées.

Une fois la lecture terminée, appuyez sur Continuer.
La notice s'ouvre et se referme d'un geste.
Le texte de la notice, première partie.
Suppression du compte et référence d'autorisation.
6Saisir ses données et consentir

Remplissez les champs marqués d'un astérisque : Prénom, Nom, Date de naissance, Sexe et Catégorie d’usager. Situation professionnelle est facultatif.

Cochez enfin la case d'adhésion et appuyez sur Confirmer et s’inscrire.

Pourquoi ces données. Prénom, nom et date de naissance permettent à l'opérateur de vérifier, à la montée, que le code est bien le vôtre. Tranche d'âge, sexe, rapport avec la ville et situation professionnelle servent à la recherche universitaire, qui les reçoit sans votre nom et sans votre adresse.
Le formulaire et la case du consentement éclairé.
Pas à pas

Monter à bord

7Inscription terminée

La coche verte confirme l'enregistrement de votre consentement. Dès lors, vous êtes participant à l'expérimentation : votre code de participation et la date d'inscription s'affichent.

Continuez avec Afficher le code pour obtenir le code d'embarquement.
Inscription achevée.
8Afficher le code d'embarquement

Le code QR est celui que l'opérateur scanne à la montée. Il se régénère toutes les quelques secondes : c'est normal et cela empêche qu'il soit réutilisé par d'autres.

Lorsque le code est lu, vos prénom, nom et date de naissance apparaissent quelques secondes sur l'appareil de l'opérateur, uniquement pour vérifier que le code est bien le vôtre.

À l'arrêt. Ouvrez la page du code peu avant de monter ; augmentez la luminosité de l'écran pour qu'il soit lu immédiatement ; ne photographiez pas le code : quelques secondes plus tard, il n'est plus valable.
Le code d'embarquement et son compte à rebours.
9Évaluer le service

Après le trajet, depuis la même page, choisissez Laisser une évaluation : touchez d'une à cinq étoiles et, si vous le souhaitez, ajoutez un commentaire. L'évaluation est facultative et peut être ignorée.

N'écrivez pas de données personnelles dans le commentaire, ni les vôtres ni celles d'autrui : le texte est lu par ceux qui analysent les résultats de l'expérimentation.
Une note et, en option, un commentaire libre.

Comment fonctionne le service expérimental

L'expérimentation se déroule en phases progressives. Les navettes électriques circulent sur un parcours dédié à une vitesse maximale de 15 km/h, avec à bord un accompagnateur toujours en mesure de reprendre la conduite manuelle. Dans la phase avec passagers, jusqu'à huit personnes assises voyagent en plus de l'accompagnateur ; le service fonctionne à la demande et les trajets sont gratuits.

Questions fréquentes

Si quelque chose cloche

Le code QR change sans cesse : est-ce un problème ?

Non, c'est le comportement prévu. Le code se régénère toutes les quelques secondes précisément pour éviter qu'il soit copié et réutilisé. Montrez-le directement depuis la page, sans le photographier.

Je ne reçois pas l'e-mail de confirmation.

Patientez quelques minutes et vérifiez les courriers indésirables. Assurez-vous d'avoir saisi correctement l'adresse. Le lien reste valable 24 heures ; passé ce délai, il suffit de recommencer l'inscription.

Puis-je monter sans m'inscrire ?

Non. Comme il s'agit d'une expérimentation, la participation exige un consentement éclairé et volontaire : l'inscription est le moyen de le recueillir.

Dois-je payer quelque chose ?

Non. Les trajets de l'expérimentation sont gratuits et l'inscription est sans frais.

Faut-il télécharger une application ?

Non. Le service est une page web : elle s'ouvre dans le navigateur du téléphone à l'adresse app-tpl.comune.imperia.it.

J'ai changé d'avis : puis-je retirer mon consentement ?

Oui, à tout moment, avec Supprimer votre compte dans la barre supérieure. Dès lors, vous ne pourrez plus monter à bord, sauf à vous inscrire de nouveau.

Mes déplacements sont-ils enregistrés ?

Non. Seule la position du véhicule au moment de la montée est mémorisée. Le trajet que vous effectuez n'est pas suivi.

Dois-je présenter une pièce d'identité ?

À la montée, le code QR suffit : vos données apparaissent sur l'appareil de l'opérateur, qui ne les utilise que pour vérifier que le code est bien le vôtre.
